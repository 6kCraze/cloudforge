# Demo images

Three original geometric illustrations generated for CloudForge: `alpine-lake.png`, `desert-dusk.png`, and `orbit-study.png`. Each is 640 × 400; the last includes transparency. These are deliberate public demo inputs, not private user uploads or test storage.

**SPDX-License-Identifier: CC0-1.0.** These illustrations and their generator are dedicated to the public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). No external photographs, brands, or personal information are included.

Select all three in the browser workspace. The worker produces proportional 320 × 200 PNG thumbnails. The original images are already included; no generator or Python installation is needed to run the application. To regenerate the same artwork for authoring purposes, run `python samples/generate.py` with Pillow installed.
